# A 60-second Drift walkthrough

1. Start Ollama and `python app.py --demo`. Open http://127.0.0.1:8778.
2. Show the six synthetic loose files and the **sample folder** label. No personal folder is involved.
3. Select the installed `llama3.1:8b`. Leave the sample-only short text previews enabled.
4. Click **Make a quiet plan**. This is a real local model request; let the progress message show. The first recorded run took 17.56 seconds.
5. Show that the client brief goes to Work, revision notes to Study, receipt to Receipts, bird article to Read Later and picnic note to Personal. The vague note stays put. The exact wording can vary across runs/models.
6. Select the receipt and click **Approve selected moves**. Open History and show its successful move.
7. Click **Undo**. The receipt returns to the loose-file inventory and the journal shows `restored`.
8. Export the plan before moving if you want the full model provenance. Exports from a real folder can contain personal paths/excerpts; review before sharing.
